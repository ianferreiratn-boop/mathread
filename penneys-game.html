Penney's Game e sequências de moedas

Penney's game é um jogo de probabilidade em que padrões de caras e coroas competem para aparecer primeiro em uma sequência de lançamentos.

Vocabulário útil

coin toss = lançamento de moeda · heads = cara · tails = coroa · pattern = padrão · waiting time = tempo de espera · first occurrence = primeira ocorrência · overlap = sobreposição · competing patterns = padrões concorrentes.
